FRAMTIDSKASSAN

Enterprise Agentic Architecture

Using smart AI assistants to organize, check, and manage Swedish social insurance applications.

The Bottleneck
01.

The Human
Bottleneck.

Unscalable Infrastructure

Current digital forms force people to fit their complex real-life situations into strict categories. When a situation doesn't perfectly fit the form, applications end up in the wrong place.

The Delay Trap: This causes huge delays. A single missing document or confusing question can leave an application stuck for weeks while it bounces between departments.

Highly-trained caseworkers end up doing basic data entry and manually checking documents, which slows down the whole system.

The Solution
02.

Smart
Automation.

The AI-First Paradigm

We separate the heavy paperwork from the final decision.

Instead of making citizens figure out complex forms, our smart system takes their natural words and directly connects them to the right rules.

The system acts like a tireless assistant—gathering the exact proof needed, checking identities, and reading documents before a human caseworker even looks at the file.

Pipeline Architecture
03. THE DATA FLOW

1. User Input

The citizen describes their situation naturally. The system safely sends this text forward.

→

2. Secure Preparation

The system safely gathers the user's text and gets any uploaded files ready for the AI to process.

↓
N8N: THE CONNECTION LAYER

3. Sorting Assistant (Agent 1)

Figures out which of the 8 benefits applies. Asks the user for more details if it's unsure.

→

4. Specialist Assistant (Agent 2)

Loads the exact rules needed. Asks the citizen the right questions and checks their uploaded documents.

→

5. Check & Move Forward

Checks if everything is done. If the file is complete, it moves to the final step.

↓

6. Secure Storage

The database safely stores the chat, the AI's notes, and the checked documents.

→

7. Human Final Review

The neat, pre-checked file goes to the dashboard for a human caseworker to review and approve.

AI Strategy
04.

The AI
Team.

Beyond Chatbots

We built a team of specialized AI assistants.

The Sorter Agent: Agent 1 guards the front door. It cannot make final decisions. If it isn't completely sure what the user needs, it stops and asks for more details, preventing errors early.

The Specialist: Agent 2 is a flexible worker. Once the benefit is known, it is given the exact rules for that benefit. It instantly becomes an expert capable of checking uploaded documents and matching them with database records.

Data Integrity
05.

Maximum
Security.

Fixing AI Weaknesses

Protecting personal data from the risks of standard AI.

The Standard AI Problem: Normal AI tools can be tricked, make things up, and leak data. They are not safe enough for handling personal information.

Our Secure Setup: We use a secure middle layer and self hosted n8n so the user's browser securely talks directly to the AI( for the demo). Also, our custom filter cleans the AI's response, making sure only safe, structured data goes into the database.

The Future - Local AI: To ensure total data control and GDPR compliance, our system is built so we can easily swap cloud AI for local AI models. This means no citizen data will ever leave the agency's own servers.

Completion
Innovation Project
06.

Human in
the Loop

The Human Factor

The AI assistants do not make the final decision.

By using AI to handle the hard work—understanding the user, collecting data, and checking documents—we give the human caseworker a perfectly organized and clear file.

We get much faster and more efficient, but the final responsibility always stays in human hands.
